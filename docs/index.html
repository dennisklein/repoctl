repoctl

Build signed RPM repositories from a package set.

repoctl is one Go binary with a CLI, a local web UI and an MCP server for agents, all on one core. It builds each package in a mock chroot, signs the RPMs with personal keys and publishes each repository as a snapshot in GHCR. repoctl runs on Fedora and builds for EL9 and EL10.
