User manual

repoctl

Build signed RPM repositories from a package set.

This manual is for the admin who builds and publishes a set. It tells you how to install repoctl, how it thinks, and which command to run for each task. Start with the tutorial: it builds a new set, slurm 26.11, from the old set.

Start the tutorialInstall repoctl

The work of an admin

An admin does the same loop for each change. repoctl does the slow and exact parts. You decide when to publish.
