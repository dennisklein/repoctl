Glossary

This page gives the project words of repoctl. The CLI, the web UI, the MCP server, the skills and all chapters use each word with one meaning. Each entry names the chapter that explains the word.

In the chapters, the first use of a word in a section has a dotted underline and is a link to its entry here. Move the pointer onto the word, or move the focus to it, to see the definition. The web UI marks the words in the same way. The colour and the icon show the domain of the word.

The data is docs/assets/glossary-data.js. To add a word, add an entry there. The build makes this page from it and links the words (design record).
