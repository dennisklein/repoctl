Components

Shared parts of the repoctl web UI. Owner: ui-shell. Classes come from repoctl-base.css, base-fixes.css and shell.css.

Status pills: node states in a run

PillClassMeaning
queued.pill.st-queuedReady. Waits for a free job slot.
waiting.pill.st-waitingDependencies are not done yet.
running.pill.st-runningBuilds now (srpm, rpm or stage).
ok.pill.st-okBuilt in this run.
cached.pill.st-cachedKey is in the node cache. Not built.
failed.pill.st-failedThe build failed.
blocked.pill.st-blockedA dependency failed.
canceled.pill.st-canceledThe run was canceled.
skip.pill.st-skipExcluded by a filter (plan only).

Plan actions use their own pills: build cached skip. The build action is an outline in the primary color. It is not a run state.

Other things with a state use the same colors: green ok, amber needs attention, red failed. Example: lock modified lock clean. Each pill has a text label. Color is never the only signal.
