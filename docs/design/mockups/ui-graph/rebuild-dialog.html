What happens
  1. repoctl adds one empty commit to each package branch.
  2. repoctl pins the new commits in repoctl.lock. You commit the lock.
  3. The plan shows pmix and prrte with action build, reason rebuild, on el9 and el10.
  4. Dependents of pmix and prrte (slurm, openmpi) are not rebuilt. The soname check runs after the build and tells if they must be.
Same as
repoctl rebuild pmix prrte --reason "hwloc-devel 2.11.2 in EPEL 9"
Commits are local; push is your step. repoctl does not push. Run git -C packages/pmix push origin pmix/slurm-26.05 (and the same for prrte) when you are ready.
