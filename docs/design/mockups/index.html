repoctl mockups

Static HTML mockups of the repoctl web UI and terminal. Files with v2 show the new build model (repo as state, advisories, agent buttons) and the publish v2 pages (snapshots, per-target publish, signing). Pages of the first version carry a superseded banner. Design documents: 04-cli-ui.html, 03-build-state.html.
