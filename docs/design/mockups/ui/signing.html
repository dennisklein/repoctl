Rulesgates 1–3 · keys change in the CLI only
  • Gate 1: the signer key is active and valid for 30 days or more.
  • Gate 2: the signer key has a deployment record for each target of the publish. A human confirms it, because repoctl has no feedback from the clients.
  • Gate 3: the key is OpenPGP v4, RSA 2048 or more, or Ed25519.
  • Publish keeps old signatures. repoctl repo resign signs them again.
  • This page does not add, retire or remove a key. These commands change the trust set: repoctl sign add, sign retire, sign remove.
